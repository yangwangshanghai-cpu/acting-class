# Acting Class 项目说明（中文）

## 项目用途
这个仓库是一个基于 React 的前端原型项目，定位是“表演教学/导演创作辅助工具”界面雏形。

从当前代码看，它的核心意图是：
- 提供一个可输入“表演主题”的输入框。
- 通过“生成创意脚本”按钮，后续可接入大模型生成排练脚本、角色练习、即兴任务等内容。

目前仓库还处在早期模板阶段，页面结构简单，部分业务逻辑尚未实现（例如按钮尚未绑定调用流程）。

## 主要文件夹与文件
- `src/`：React 源代码目录（页面组件、样式、入口文件、测试文件）。
- `public/`：静态资源目录（HTML 模板、图标、manifest 等）。
- `node_modules/`：依赖安装目录（由 `npm install` 生成，通常不手工修改）。
- `package.json`：项目依赖与脚本命令定义（如 `start`、`build`、`test`）。

## 如何运行
1. 安装依赖：
   ```bash
   npm install
   ```
2. 启动开发环境：
   ```bash
   npm start
   ```
3. 浏览器访问：
   - 默认地址通常是 `http://localhost:3000`

可选命令：
- 运行测试：`npm test`
- 打包生产版本：`npm run build`

## Codex 可以帮导演和表演老师做什么
你可以把 Codex 当成“教学设计 + 创作执行 + 技术落地”的助手。典型工作包括：

### 1) 教学内容与课堂设计
- 设计分层训练方案：初级/中级/高级表演课大纲。
- 按教学目标生成课堂流程：热身、观察、即兴、复盘。
- 输出可打印讲义：动作练习、情绪调动、角色任务卡。

### 2) 导演创作与排练支持
- 按题材快速生成多版本短场景（现实主义/荒诞/喜剧）。
- 为同一场戏生成不同“导演阐释角度”和调度建议。
- 设计角色小传、人物关系网、冲突升级路径。

### 3) 演员训练与反馈体系
- 生成“逐周训练计划”（台词、肢体、节奏、听对手）。
- 制作可量化反馈表：目标、观察点、改进建议。
- 把排练记录整理成“个体成长档案”。

### 4) 工具化落地（这个仓库可继续扩展）
- 在当前输入框基础上接入 OpenAI API：一键生成训练脚本。
- 增加“风格/难度/人数/时长”参数，输出更可控。
- 增加历史记录、课程模板库、学员分组与导出功能。
